# MAIN FAM media kit
### Welcome to the main fam digital memorabilia and identity media archives

The `MAIN FAM 0P3RAT0R C0LLECT1VE` is a formally organized No Man's Sky civilization birthed during the events of Project Skyscraper.
This archive serves as a "press kit" media repo of sorts.

You can download any MAIN FAM media available at the Github page [website here](https://yourbasicmaths.github.io/ps/MAINFAM/media_archive/): `https://yourbasicmaths.github.io/ps/MAINFAM/media_archive/`
Or feel free to navigate into the /assets folder of the MAINFAM subdirectory if you prefer.
